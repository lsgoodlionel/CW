文档版本 1.2.0 · 备份格式 v20 · 更新于 2026-09-09

1. 系统简介

本系统是面向小微企业、基于《小企业会计准则》的完整财务记账 Web 系统。前后端分离,复式记账,自动生成官方格式财务报表与全套会计账簿,并内置往来单位、人员组织、审批流程、费用申请与报销、用户与权限、数据备份、操作日志等模块。通过 Docker 一键部署到 Ubuntu 服务器。

模块用途
记账凭证复式记账录入、附件上传预览、红字冲销、凭证关联
财务报表资产负债表 / 利润表 / 现金流量表(会小企格式)+ 科目汇总,月/季/年,导出 Excel
会计账簿总账、明细账、日记账等六类账簿,自动生成,导出 Excel
往来单位 / 人员企业客户/个人/供应商/往来单位;组织架构与员工(支持一人多岗)
流程设计 / 审批中心可视化设计审批流程;审批中心处理待办(与流程设计分权限)
费用申请 / 费用报销事前审批 + 事后报销闭环;通过后一键生成凭证,附件同步、自动归档审批记录单
用户与权限全站强制登录 + RBAC 角色权限矩阵 + 按部门职位授权预设
数据备份 / 操作日志整站一键导出/导入;全系统行为留痕含修改详情

2. 服务器安装部署

准备一台全新的 Ubuntu 云服务器(建议 2 核 2G 及以上),使用具备 sudo 权限的账号登录后执行一行命令,自动完成「安装 Docker/git → 拉取代码 → 构建启动」。

curl -fsSL https://raw.githubusercontent.com/lsgoodlionel/CW/main/install.sh | bash

自定义端口 / 安装目录

curl -fsSL https://raw.githubusercontent.com/lsgoodlionel/CW/main/install.sh | HTTP_PORT=80 APP_DIR=/opt/cw bash
安装完成后,浏览器访问 http://服务器IP:8080(或你设定的端口)。本机测试为 http://localhost:8080。
若一行命令报 bash: 行 1: 404: 未找到命令:多为 GitHub raw 短暂缓存或命令被复制不全。请确认命令含 -f 后重试,或先下载再执行:
curl -fsSL .../install.sh -o /tmp/install.sh && bash /tmp/install.sh

本地桌面(Windows / macOS)一键安装客户端

在个人电脑上把系统当"本地客户端"使用。前置:先安装 Docker Desktop(docker.com/products/docker-desktop)。安装脚本会自动下载代码 → 构建 → 启动 → 打开浏览器;再次运行即"更新并启动"(数据保留在 Docker 数据卷,不丢)。

  • macOS:终端执行 curl -fsSL https://raw.githubusercontent.com/lsgoodlionel/CW/main/install-mac.command | bash;或下载 install-mac.command 后右键 → 打开(首次需在“系统设置 → 隐私与安全性”允许)。
  • Windows:下载 install-windows.bat 后双击运行(Windows 10+ 自带 curl/tar,无需额外工具)。
启动后自动打开 http://localhost:8080,初始账号 admin / admin123。停止:在 Docker Desktop 停止 CW 容器,或到安装目录执行 docker compose stop。

无需 Docker 的原生安装包(Windows / macOS / Linux)

把整个系统打包成单个可执行文件:一个进程同时跑后端、托管前端、用 SQLite 存数据(用户数据目录),运行后自动开浏览器。无需安装 Docker / Python / 数据库,适合单机离线使用。

  • 获取:GitHub Releases 下载对应平台的 CWFinance(Windows 为 CWFinance-windows.exe),双击运行。初始账号 admin / admin123。
  • 自行构建(目标系统需 Node 18+、Python 3.11+):macOS/Linux 运行 packaging/build-native.sh,Windows 运行 packaging/build-native.ps1。
  • 数据位置:Win %APPDATA%\CWFinance / mac ~/Library/Application Support/CWFinance / Linux ~/.local/share/CWFinance。可在「数据备份」导出迁移。
原生版适合单机/单人;多人或服务器仍建议用 Docker(PostgreSQL)版。两者数据可用备份 zip 互导。

手动部署(可选)

git clone https://github.com/lsgoodlionel/CW.git && cd CW
./deploy.sh          # 自动生成随机数据库密码的 .env 并构建启动

3. 首次登录与初始化

系统全站强制登录。首次打开显示登录页。初始超级管理员账号:

用户名初始密码
adminadmin123(或部署时 .env 里的 ADMIN_PASSWORD)
务必第一时间修改初始密码:登录后点右上角用户名 → 修改密码。生产环境还应在服务器 .env 设置随机的 AUTH_SECRET。

整体界面布局

4. 管理员设置(建议按顺序完成)

  1. 企业信息:菜单「企业信息」填写单位名称、税号、注册地址、开户行、法人/会计/审核人等。报表抬头与备份都会用到。
  2. 会计科目:系统已内置标准科目与常用明细(二级)科目。可在「会计科目」增删改、导入二级科目模板、导出全部科目。
  3. 人员与组织:「人员管理」搭建部门(组织架构)与员工;给员工设置职位类型。关键审批要用到管理层/股东,见下。
  4. 审批流程:「流程设计」查看/修改系统预置的「费用申请审批流程」「费用报销审批流程」,或新建流程。
  5. 用户与权限:「用户与权限」新建子账号、分配角色;必要时新增自定义角色、配置授权预设。

4.1 设置审批人(务必)

审批人来自「人员管理」的员工职位。预置的费用申请/报销流程按「部门负责人 / 任一管理层」自动找审批人,其中股东高于管理层、也可审批。请至少给一名员工(如财务负责人)设置「管理层」或「股东」职位,否则提交的单据将无人可审批。

是否就绪可在「流程设计」页顶部看到:若缺审批人会显示橙色告警并指出是哪条流程的哪一步。

审批人类型谁来批前置设置
指定员工流程里选定的人在流程步骤里选具体员工
按角色拥有该职位类型的人人员管理里有对应职位
部门负责人申请人所在部门的管理层/股东该部门有管理层或股东
任一管理层任意管理层(无则股东兜底)公司有任一管理层或股东

4.2 角色与权限

系统预置三个角色:只读查看、财务操作、审批人。可在「用户与权限 → 角色与权限」新建自定义角色,勾选各模块的 查看/新建/编辑/删除/审批 权限。

流程设计与审批中心已拆为两个独立权限模块:给只审批不做流程设计的人,分配「审批中心:查看 + 审批」即可;流程管理员再加「审批中心:编辑/删除」用于改派/撤销/删除卡住的流程。

新建用户

  1. 「用户与权限 → 用户」→ 新建用户,填用户名、显示名、初始密码。
  2. 勾选角色(可多选);如需按登录账号自动识别审批身份,建议绑定到对应员工。
  3. 保存。该用户即可用自己的账号登录,菜单按其权限显示。

授权预设(可选)

「授权预设」可按「部门 + 职位类型 → 系统角色」预先配置,新建用户时一键带出角色,便于批量授权。新增角色后,授权预设/用户弹窗的角色下拉会自动同步最新角色。

5. 日常使用

5.1 记账凭证

  1. 「记账凭证 → 新建凭证」。填凭证日期、摘要。
  2. 逐行录入分录:选会计科目、二级明细科目,填借方或贷方金额(一行只填一方)。
  3. 底部实时校验 借贷合计相等(允许红字负数)。平衡后保存。
  4. 可上传附件(发票/回单/合同/完税证明),支持在线预览、修改类型、删除。
  5. 红字冲销:对已记账凭证可「红字冲销」,自动按原凭证生成金额取负的红字凭证并建立「冲销」关联。
  6. 复制新建:在凭证列表点某条凭证的「复制新建」,把它的摘要/科目/明细/金额复制成一张新凭证(日期取当天、单号留空自动生成、不带原附件与关联),核对后保存即可,适合每月重复性凭证。
凭证一经保存即计入报表与账簿(实时汇总),无需额外过账;仅「已过账(posted)」凭证进入报表,草稿不影响账簿。

列表检索:凭证列表顶部支持按日期区间、凭证号/摘要关键字、往来单位、费用/科目类型(选具体科目)、收支类型(收入/支出,按分录损益科目方向)组合筛选,快速定位目标凭证。凭证详情还可反向关联合同。

5.2 往来单位

管理企业客户 / 个人客户 / 供应商 / 往来单位,用于凭证关联、应收应付与往来对账。

  1. 「往来单位 → 新建」:选往来类型,填名称、简称、税号、开户行/账号、联系人等;简称用于凭证/合同下拉显示。
  2. 凭证录入、合同、报销均可选择往来单位;凭证列表可按往来单位筛选。
  3. 删除保护:被凭证或合同引用的往来单位不会硬删除,改为停用(保留历史引用)。

5.3 人员管理

搭建组织架构与员工档案,是审批人解析的依据。

  1. 「人员管理」新建部门(支持上下级);有下级的部门不可删除。
  2. 新建员工:填姓名、工号、入职/离职日期、身份证、持股比例等;一名员工可在多个部门任多个职位(股东/管理层/普通员工/其他)。
  3. 审批人按此处「部门负责人/管理层/股东」职位解析;离职日期用于小型微利季度平均从业人数的精确计算。
  4. 被历史申请/报销/审批引用的员工不会硬删除,改为离职(停用)。

5.4 会计科目

维护一级科目与二级明细科目(《小企业会计准则》科目体系,系统已预置)。

  1. 展开一级科目查看/新增其二级明细科目(编码在一级编码后自动延续)。
  2. 可导出全部科目 Excel;下载二级科目导入模板后可批量导入。
  3. 凭证录入时二级明细可即输即建;被凭证引用的科目受删除保护。

5.5 会计账簿

总账、明细账、日记账等六类账簿按凭证自动生成,无需手工登账。

  1. 选择账簿种类 + 年/月/季,页面即时呈现。
  2. 一键导出 Excel:可导单类,或导出全套六 sheet;数据与页面一致,仅含已过账凭证。

5.6 财务报表

资产负债表、利润表、现金流量表(官方会小企 01/02/03 格式)与科目汇总表,数据由已过账凭证实时汇总。

  1. 切换月/季/年与参照期间查看四张报表;行次有上下级隶属与缩进。
  2. 一键导出 Excel:1:1 还原模板版式,含资产负债表/利润表/现金流量表/科目汇总表四个 sheet。
  3. 勾稽:资产=负债+所有者权益;利润表净利润=资产负债表未分配利润当期变动。

5.7 流程设计

可视化设计审批流程:设置业务类型(通用 / 费用申请 / 费用报销 / 合同 / 税务申报 / 记账凭证(大额))、多步骤、每步审批人类型。系统已预置费用申请、费用报销两条流程,可直接查看/修改审批人与步骤;合同/税务/大额凭证如需审批,在此新建并启用对应业务类型的流程即可。

业务类型的意义:提交单据时,系统按「业务类型匹配 + 已启用」自动挑选流程发起审批。每种业务类型建议只保留一条启用流程。
直录 / 审批 双通道(合同 / 税务 / 大额凭证):在「用户与权限」为角色勾选对应模块的「直录(免审)」权限,则该角色录入后直接生效;未授权角色在已启用该业务审批流程时,录入将保存为草稿并需「提交审批」,审批通过后自动生效(合同→履行中、税务→已申报、大额凭证→过账入账)。大额凭证的金额门槛在「企业信息 → 大额凭证审批阈值」设置(0=不启用)。若未启用相应审批流程,则有新建权限即可直接录入。

5.8 费用申请(事前审批)

  1. 「费用申请 → 新建费用申请」,选申请类型(一般/合同/常规费用),填事由与预计费用明细。
  2. 上传附件(如合同):选择文件后立即上传并显示进度,与保存解耦。
  3. 提交审批,走「费用申请审批流程」。通过后可据此发起报销。

5.9 费用报销(事后管理)

  1. 「费用报销 → 新建报销单」。可关联已通过的费用申请,自动带出事由、明细及其关联合同;也可直接关联合同。
  2. 逐条填报销明细:费用类别、费用科目、明细科目、金额;上传发票/回单等附件(即时上传显示进度)。
  3. 提交审批 → 在「审批中心」通过 → 回到本页点「生成凭证」(借各费用科目 / 贷银行存款)。
  4. 生成凭证时:报销、关联申请及关联合同的附件自动同步到凭证附件;若关联了合同,还会自动建立凭证↔合同关联;并自动生成一份「费用审批记录单」PDF归档(含事前申请与报销完整审批轨迹)。
  5. 历史凭证若缺审批记录单,可对「已生成凭证」的报销单点「补生成审批单」。
模块衔接关系(单据流):合同 → 费用申请(可关联合同)→ 费用报销(可关联申请/合同,自动带入明细与附件)→ 审批 → 生成凭证(自动继承报销/申请/合同附件 + 自动关联合同 + 归档审批单)。凭证页也可反向关联合同;合同详情可查看其关联的全部凭证,形成履约台账闭环。

5.10 审批中心

所有走流程的单据在此处理(与「流程设计」是两个独立页面/权限)。

  1. 顶部「当前审批人身份」默认取登录账号绑定的员工;未绑定可手选或到「用户与权限」绑定。
  2. 「我的待办」列出轮到你审批的单据,点通过 / 驳回(可填意见)。
  3. 点标题查看完整申请内容 + 审批流程链:每步状态、当前卡在谁、后续预计审批人。
  4. 流程管理权限者可对进行中的单据改派处理人 / 按流程自动匹配 / 撤销 / 删除(撤销、删除会把关联单据退回草稿,便于修改后重交)。

5.11 操作日志

全系统行为留痕(含修改前后差异详情、操作人、耗时、IP)。按类型 + 年/月/季查询,展开看详情,一键导出 PDF。

5.12 仪表盘

首页概览分为四区,支持按月/季/年 + 参照日期切换统计周期:

  1. 经营成果 + 资产负债:营业收入、总支出、净利润、货币资金,以及资产总额、负债总额、所有者权益、银行存款等。
  2. 财务分析比率:资产负债率、毛利率、净利率,配合往来款、应交税费等,快速判断经营与偿债状况。
  3. 运营待办:审批进行中、待生成凭证、报销审批中、费用申请待审、履行中合同、税务待申报、往来单位、在册员工、凭证总数等,卡片可点击跳转对应模块。
  4. 趋势与构成:近 6 个月收支趋势图、支出构成。

5.13 合同管理

  1. 「合同管理 → 新建合同」:填合同编号、名称、收支方向(收入类=我方提供/收款、支出类=我方接受/付款)、类型(销售/采购/服务/租赁/劳务/借款/其他)、含税金额与税率(自动价税分离出税金)、对方单位(可搜索选往来单位或直接手填名称)、签订/起止日期、我方签署人、对方联系人、状态等。
  2. 可上传合同附件(扫描件等),选择后即时上传显示进度。
  3. 点合同编号进「详情」,可关联记账凭证:选择凭证后「关联」,一份合同可关联多张分期收付款凭证;可移除关联、跳转查看凭证。
  4. 合同也会被费用申请/费用报销选择关联:报销生成凭证时,合同附件随之归档、并自动建立凭证↔合同关联(见 5.9)。列表可按合同状态筛选,并显示收支方向标签。

5.14 税务管理

「税务管理」分两个标签:

  • 税务申报记录:登记各税种(印花税/增值税/增值税及附加/企业所得税/个人所得税/其他)、纳税人类型(国税企业 / 自然人)、所属期、计税依据、应纳税额、已缴税额、申报日期、状态,并可上传申报/完税凭证附件。
  • 应纳税报表:支持季度预缴(A200000)与年度汇算(A100000)两种主表切换:
    • 季度预缴(A类 A200000)——选年度+季度,按账套数据自动计算本年累计(年初→季末)各行次(营业收入→利润总额→实际利润额→应纳所得税额),含子行次(1.1/9.1 等)并按行次层级缩进显示。
    • 年度汇算(A类 A100000 主表)——选年度,按账套全年数据计算利润总额→纳税调整后所得→应纳税所得额→应纳税额→实际应补(退)税额,含「利润总额计算/应纳税所得额计算/应纳税额计算/实际应补(退)税额计算」类别分组与层级缩进。
    两种表均可页面预览并导出 Excel(格式对齐国税局表式)。境外所得、纳税调整、各类优惠、预缴税额、总分机构分摊等无法从账套自动取得的行次默认 0,导出后可结合各附表按实际手工调整再报送。
说明:年报导出已含 A100000 主表 及 A101010 收入 / A102010 成本 / A104000 期间费用 / A105000 纳税调整 / A106000 弥补亏损五张附表。前三张自动取数;A104000 按二级科目名称关键字归集(列合计=各期间费用发生额)。A105000 纳税调整可录入账载/税收/调增/调减,联动主表行20/21;A106000 弥补亏损可录入各年度亏损额与本年弥补额,联动主表行26。
纳税人身份:在「企业信息」设置增值税身份(一般/小规模)与「小型微利企业」;启用小型微利后,季报/年报自动计算减免所得税额(应纳税所得额×20%,实际税负5%)。A105080 资产折旧摊销可录入账载/税收折旧,纳税调整=账载−税收,联动 A105000 行32;A107012 研发费用加计扣除可录入各研发费用与加计比例,加计扣除总额联动主表行22。A105050 职工薪酬可录入账载/实际发生/税收金额,纳税调整=账载−税收,联动 A105000 行14;A105060 广宣费录入本年支出/扣除率/以前结转,扣除限额=营业收入×扣除率,纳税调整联动 A105000 行16。年报导出 Excel 现含 A100000 主表 + A101010/A102010/A104000/A105000/A105050/A105060/A105080/A106000/A107012 共 10 张表。
季报附表 A201020 资产加速折旧:季报新增「加速折旧」录入 tab,纳税调减金额联动季报主表行21;季报导出含 A200000+A201020。
税收优惠事项:年报/季报均设「税收优惠」录入 tab,按国税码表(免税收入/减计收入/所得减免/减免所得税额)填金额,自动联动主表——免税减计加计→行22、所得减免→行25(季报23)、减免所得税额→行31(季报28)。
增值税及附加税费申报表(小规模):「应纳税报表」新增第三类,按季度从账套销售额自动计算,征收率可选1%/3%,季销售额≤30万免征,附加税费(城建/教育/地方教育)按小微六税两费减半,支持预览与导出。
自动复核:报表页顶部提供可折叠的「小型微利复核 / 增值税身份复核 / 年度季度核对」——默认仅显示简要结果,点击展开完整明细与判断依据。

6. 数据备份与恢复

  1. 「企业信息 → 数据备份」→ 一键导出备份:把企业信息、科目、全部凭证与附件、用户角色、审批、费用单据等打包为一个 zip。
  2. 迁移或还原:在同一页导入 zip,整体替换现有数据。
最新版导出覆盖各模块全部信息(含企业信息全字段:税号/地址/开户行/行业/本位币/准则/启用期间等)。导入为整体替换,请先导出当前数据做好备份。
导入旧版本(无用户模块)的备份后,系统会自动保证仍有可登录的超级管理员(admin / ADMIN_PASSWORD),不会被锁死;登录后请重设密码与子账号。

7. 一键升级

在服务器上任意目录执行一行命令即可升级(自动定位部署目录):

curl -fsSL https://raw.githubusercontent.com/lsgoodlionel/CW/main/upgrade.sh | bash

升级流程:升级前自动备份 → 获取最新代码(git 不通时自动改用 HTTPS 归档下载)→ 重建并重启容器(保留数据卷、数据不丢) → 健康检查。

升级完成后请在浏览器按 Ctrl+Shift+R 强制刷新清缓存,以看到新功能。若提示「已是最新且容器已为该版本」但仍未见新功能,可用 FORCE=1 强制重建。
首次升级到较新版本时,「升级前备份未成功」的提示属正常(旧容器尚无新备份模块);数据卷完整保留、数据不丢,之后升级即恢复正常。

8. 一键卸载

危险操作,不可恢复。会停止并删除容器、删除数据卷(数据库 + 附件)。默认会在卸载前把数据导出到仓库目录之外做一次安全备份。
ASSUME_YES=1 bash -c "$(curl -fsSL https://raw.githubusercontent.com/lsgoodlionel/CW/main/uninstall.sh)"

在仓库目录内运行 ./uninstall.sh 会交互式要求输入 yes 确认。可选环境变量:

变量作用
ASSUME_YES=1跳过确认(管道/非交互必须设置)
NO_BACKUP=1跳过卸载前备份
PURGE_DIR=1连同代码目录一起删除
KEEP_IMAGES=1保留本地构建镜像
重装后可在「数据备份」页导入卸载前保留的备份 zip(默认在 $HOME/cw-uninstall-backups/)恢复数据。

9. 常见问题 FAQ

点导出/预览提示「未登录或登录过期」?

已修复;若仍出现请强制刷新浏览器(Ctrl+Shift+R)清缓存后重试。

提交单据提示「未配置审批流程/无人可审批」?

到「人员管理」给至少一名员工设「管理层」或「股东」职位;并确认「流程设计」里对应业务类型有一条启用的流程。

升级后没看到新功能?

浏览器强刷清缓存;或 FORCE=1 重新执行升级命令强制重建容器。

数据会不会在升级/卸载时丢失?

升级保留数据卷,数据不丢;卸载会删除数据卷,但默认会先导出一份安全备份到仓库目录之外。

忘记管理员密码?

可在服务器 .env 设置 ADMIN_PASSWORD 并重建;或用另一超级管理员账号进入「用户与权限」重置。
